# InternTrack – Excel Analysis

## Overview
This folder contains the Excel-based analysis of the InternTrack project.

## Files Included
- `InternTrack_Excel_Analysis.xlsx` – Complete workbook containing raw data, formulas, Pivot Tables, charts, and dashboard.

## Analysis Performed
- Dataset overview
- Year-wise internship application analysis
- Major student challenges
- Preferred feature analysis
- Dashboard and product recommendations

**Note:** The dataset contains simulated records created for portfolio practice. Findings should not be interpreted as actual student research.
